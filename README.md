# 청년 혜택 찾기

정부24에 등록된 공공서비스 전체(약 1만 1천 건)와 직접 조사한 청년 정책을 **내 조건과 비교해** 분야별로 보여주는 페이지예요.
혜택을 누르면 **자격조건**이 맨 먼저 보이고, 내 정보와 비교한 결과(✓ 충족 / ✕ 미충족 / ? 정보 필요 / ! 공고 확인)와 정부24 원문이 함께 나와요.

## 쓰는 법
- **웹페이지**: GitHub Pages 주소를 열면 끝. 설치·로그인 필요 없음.
- **내 PC에서**: `청년혜택_실행.bat` 더블클릭 (Node.js 필요) → http://localhost:5179

정보 넣기 (편한 쪽으로)
1. **서류 올리기**: 정부24·홈택스에서 받은 등본, 소득금액증명, 건강보험 자격득실을 PDF나 캡처로 올리면 나이·사는 곳·연봉·가구원 수를 채워요.
   읽기는 **브라우저 안에서만** 하고 서류를 어디에도 보내지 않아요.
2. **직접 입력**: 연봉, 나이·사는 곳·사는 집·지금 상황·가구원 수·해당되는 것 칩

## 정책 목록
1. **정부24 공공서비스**: 공공데이터포털 「행정안전부_대한민국 공공서비스(혜택) 정보」 API.
   GitHub Actions가 매주 월요일 새로 받아 지역별 파일(`public/data/`)로 나눠 페이지를 다시 올려요.
   API 키는 저장소 **Secrets(DATA_GO_KR_KEY)** 에만 있고 저장소·페이지에는 들어가지 않아요.
2. **직접 조사한 청년 정책** (`public/policies.js`): 공고 원문으로 조건을 정리한 항목. 정부24와 이름이 같으면 이쪽을 보여줘요.

표시 기준
- ‘조건 충족’: 직접 조사한 항목 중 내 조건이 다 맞는 것
- ‘기본 조건 맞음 · 원문 확인’: 정부24 조건 코드(나이·소득·대상)가 맞는 것. 원문 자격을 꼭 확인하세요
- 청년 대상 사업을 먼저 보여주고, 전 연령 대상 일반 서비스·조건 안 맞는 것·마감된 것은 접어 둬요

판정은 참고용이에요. 신청 전 공고 원문을 꼭 확인하세요.

## 개발
- `npm run data`: 정부24 목록 받기(.env 의 DATA_GO_KR_KEY) + 지역별 파일 만들기
- `npm start`: 로컬 서버 (키가 있으면 7일 지난 목록 자동 갱신)
- 라이브러리: pdf.js(legacy), tesseract.js — `public/vendor/` (각 LICENSE 포함). 한글 글자 인식 데이터는 처음 쓸 때 CDN에서 받아요.
